# WeldCheck project scope

## Approved direction

**Development of a Web-Based Pre-Welding Checklist and Weld Quality Inspection System for Shielded Metal Arc Welding of Mild Steel**

WeldCheck is a web-based system for guiding SMAW pre-welding preparation, recording welding information, assessing visible weld quality from photographs, and maintaining clear inspection records, with additional support for completed-weld checks and guided practice.

## Aim

The aim of this project is to develop a web-based pre-welding checklist and weld quality inspection system for Shielded Metal Arc Welding of mild steel.

## Objectives

1. Develop a pre-welding checklist and setup-checking procedure for Shielded Metal Arc Welding of mild steel.
2. Prepare and document selected mild-steel weld samples under controlled workshop conditions.
3. Develop a web-based system for recording welding information, assessing visible weld quality from uploaded photographs, and maintaining inspection records.
4. Evaluate the developed system using the prepared mild-steel weld samples and selected reference conditions.

## Product and research boundaries

The product can support real welding jobs, completed-weld checks and guided practice. The final-year study remains limited to SMAW, mild steel, the selected controlled samples and visible-surface assessment.

The primary product workflow is:

> Record welding job → confirm setup and preparation → weld → photograph → assess visible surface → confirm → report.

Completed-weld checking is an additional workflow. Guided practice is optional and is not the centre of the study.

WeldCheck does not determine internal weld condition, penetration, mechanical strength, safety or welding-code compliance. A photograph cannot replace suitable tests, an applicable procedure or qualified review.

## Objective-to-evidence matrix

| Objective | Method | Required evidence |
|---|---|---|
| Pre-welding procedure | Define applicable settings and preparation checks | Implemented setup comparison and completed checklist records |
| Controlled samples | Produce, identify and photograph selected SMAW mild-steel samples | Physical samples, sample register, settings and photographs |
| Web system | Implement and test the complete WeldCheck workflow | Deployed application, functional tests and printed inspection records |
| Evaluation | Compare saved WeldCheck condition sets with documented references | Reference provenance, comparison results, exported data and discussion |

Features such as authentication, cloud storage, administration and export support system delivery. They are not separate research objectives.
