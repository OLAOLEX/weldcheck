# Support

For setup questions, first read the [README](README.md) and the in-app [user guide](https://weldcheck.cc/guide).

- Use a GitHub issue for reproducible bugs and feature proposals.
- Use private vulnerability reporting for security problems.
- Do not post API keys, private weld photographs, user records or Supabase service-role keys.

WeldCheck is an educational visible-surface inspection and record project. Project support cannot certify a weld or provide an engineering safety decision.
